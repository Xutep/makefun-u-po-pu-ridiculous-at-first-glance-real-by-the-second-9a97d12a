# Ridiculous at First Glance, Real by the Second

Entry for the make.fun bounty
[u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

`main.py` (Python 3, standard library only) writes one sentence — at most
200 characters — pitching a startup idea so strange it sounds like a joke,
yet specific enough that a reader can see the customers and the money:

> We rent herds of goats to mow corporate lawns: tech campuses pay $800 a
> month per herd, the goats eat the grass, fertilize it, and staff get a
> lunchtime petting zoo.

Run it with `python3 main.py`; it writes the sentence to `/output/entry.txt`.
